Script rules

A rule changes a script before it runs, on sites where you've turned on script rewriting. Each change finds a line of text and must match exactly once. If the site updates its script and the text moves, the rule stops and the original script runs.

Import from DevTools

      
Edit a script with Local Overrides in DevTools until the page behaves, then choose that overrides folder here. For each saved file, Script Guard fetches the live original, works out what you changed, and offers it as a rule. The folder is only read, never changed.

      

        
        
        
Pick the folder DevTools shows under Sources → Overrides. Your browser will say it is uploading the folder; nothing is sent anywhere, the files are only read.

        

        

      

    


    

      
Browser hardening

      
An extension can't change these settings, and they protect you against attacks on the browser itself, which nothing in this extension can stop. Check each one against your Brave version.

      

        
    
          
  • Keep Brave updated. Open brave://settings/help and restart after each update.
    • 
          
  • Shields on Aggressive. Open brave://settings/shields.
    • 
          
  • Keep site isolation on. Search for it in brave://flags.
    • 
          
  • Turn off JIT for untrusted sites if your version offers it. Look in brave://settings/security.
    • 
          
  • Block USB, HID, serial and Bluetooth by default. Open brave://settings/content.
    • 
          
  • Block notifications and pop-ups by default. Same page.
    • 
          
  • Never paste a command from a web page into Win+R, a terminal or PowerShell.
    •
